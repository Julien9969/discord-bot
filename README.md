# Discord Bot
## Description

A basic Discord bot with the following features:

- Role management (multi-server)
- User vocal time tracking and leaderboard (multi-server)
- Ability to join and play audio in voice channels
- Send DMs to users
- GPT integration (currently not working)



## Auto start :
npm install -g pm2
pm2 start npm -- run start -- --name Bot-discord
pm2 startup
exectute the command given by pm2
pm2 save
